# Digital Voting System - Mobile App

React Native mobile application for voters.

## Planned Features
- Login / Register with OTP verification
- View active elections
- Browse candidates with details
- Cast vote (one user = one vote)
- Vote confirmation screen
- View election results

## Tech Stack
- React Native (Expo)
- Redux Toolkit
- React Navigation
- Axios

## Setup (Coming Soon)
```bash
cd mobile
npx create-expo-app .
npm install
npx expo start
```
